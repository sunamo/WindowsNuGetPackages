# Repozitáře

- **SunamoLogMessage** — knihovna pro práci s log zprávami (vč. samostatného Runner projektu a testů).
- **SunamoWpf.AwesomeFont** — WPF integrace ikonového fontu FontAwesome.
- **SunamoWpf.Controls** — sada vlastních WPF ovládacích prvků.
- **SunamoWpf.Converters** — WPF value convertery pro binding.
- **SunamoWpf.Core** — jádro sdílených WPF utilit (barvy, fonty, velikosti, hotkeys, storage).
- **SunamoWpf.Data** — datové modely a rozhraní pro WPF UI (obrázky s cestou, UserControly).
- **SunamoWpf.Extensions** — rozšiřující metody (extension methods) pro WPF.
- **SunamoWpf.Helpers** — pomocné třídy pro WPF appky (práce s obrázky, soubory, fonty, rozpoznávání jazyka kódu).
- **SunamoWpf.Logging** — logování a inicializace WPF appek.
- **SunamoWpf.RegistryWin** — přístup k registrům Windows z WPF appek.
- **SunamoWpf.Storage** — správa nastavení appky a trial licencí.
- **SunamoWpf.SunamoUtils** — obecné utility pro WPF appky.
- **SunamoWpf.ToggleSwitch** — vlastní WPF komponenta přepínače (toggle switch).
- **SunamoWpf.Windows** — rozhraní a pomocné třídy pro práci s okny WPF appek.
